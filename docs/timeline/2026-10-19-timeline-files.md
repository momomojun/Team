# 10-19：时间线改成一个改动一个文件（分支 `docs/timeline-files`）

- 为什么：10-19 一天里 #25、#30、#33、#37 合并时都冲突，冲突全在文档：每个 PR 都往 `PROJECT.md` 时间线末尾加一段、改 `GOALS.md` 顶上的统计数字，同时开着的 PR 改的是同一个地方。仓库主人问“为什么老是两个 PR 都要合并但是每次都要修改”，又说别每次都叫助手改、PR 别分那么细。
- 做了什么：`PROJECT.md` 的时间线原样搬到 [2026-10-11-to-10-19.md](2026-10-11-to-10-19.md)，以后每个 PR 在 `docs/timeline/` 新建自己的文件（[README.md](README.md)）；去掉 `GOALS.md` 顶上要手动数的统计表；GUIDE 的维护规则和给 AI 助手的规矩跟着改：PR 按主题合在一起，交给仓库主人之前把所有开着的 PR 的冲突先修好。
