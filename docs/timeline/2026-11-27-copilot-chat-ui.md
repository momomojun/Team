# 11-27：Copilot 对话界面照 ChatGPT 的交互改版（分支 `ui/copilot-chat`）

- 为什么做：仓库主人说规划行程时 ChatGPT 的交互最好，让照着学。原来的对话框是首屏里一个 26rem 高的小框，回复是一大段字（每天一行、几十个景点挤在一起），选项在框外面，等回复时看不出在做什么，没有停止、复制。
- 学了 ChatGPT 的哪些：对话为主的一栏、输入框在下面并跟着字数长高；回复有层次（标题、列表、每天的时间表）；新回复一块一块出来；“正在思考”那行写着真实的这一步和秒数，做完收成一行“做了什么”（像“已思考 12 秒”），点开看细节；追问的选项放在回复里；每条回复能复制；等回复时发送键变成停止；往上翻了出“回到最新”；出错能再试一次；排好以后给几句接着说的例子。没学的：重新生成、改上一句话（Copilot 那边的会话已经往前走了，做不到真的“重来”）；点赞点踩（没有地方收，不做假按钮）。
- 做了什么：
  - `src/lib/copilot/reply-blocks.ts`（新）：把回复拆成段落、小标题、列表、每天（Writer 模板写的“第 N 天（日期）：08:00 从 X 出发 → 09:10 A、11:00 B；晚上住 Y”拆成出发、各站、住处）；“没排进去的：A；B；C”拆成小标题加列表；对不上的（模型写的说明）照原样当段落，不丢字。`tests/copilot-reply.test.ts` 4 条，有一条用的是本机 35B 真排出来的锡安 + 布莱斯 5 天。
  - `src/components/plan/copilot-chat.tsx`：还没开始时照旧是首屏（例子改成三张小卡片，发送键是图标）；一开始说话就变成对话：上面一条细标题和“新对话”，中间一栏能滚动（`min(66vh, 680px)`），输入框和提示在下面，照片压得更深。每天画成一条金线、每站一个点、时间在前，“住”在最后，这是对话框里唯一花心思的样子，别的都保持安静。等回复时的公路小画留着，最上面加了真实的这一步（“在排每天的路线”，一道光扫过）和秒数。“这一步做了什么”收成一行角色名（调度员 › 规划 agent › 行程引擎，金点是模型、白点是代码）加用了几秒，点开看每一步（11-23 仓库主人看不出多 agent 在哪，所以角色名一直写在外面）。
  - 文案：中文、英文字典各加了新对话、停止、复制、回到最新、再试一次、角色名、正在做的步骤、出发 / 住、几句接着说的例子；繁体自动转。
  - `globals.css`：`chat-in`（回复一块块淡入）、`chat-shimmer`（“正在做”那行字上的光），系统设了“减少动画”时都关掉。
- 验证：本机开 Copilot（本机 Qwen3.5 35B，不调云端）和网站，在浏览器里走了一遍“加州的国家公园 → 约书亚树 → 轻松玩”：追问、带编号的选项、排出的 3 天路线、没排进去的列表、复制、接着说的例子都对；金点和线的位置量过（差 0.3 像素）；手机宽度（375）没有横向滚动；“停止”按下以后显示“已经停下了”、发送键回来。网站 240 个测试、tsc、eslint 都过。
- 线上验证（11-27，仓库主人允许用线上测试、不用完免费额度就行）：本机网站连线上正式的 Copilot（0.7.1，Gemini），说了 3 句（约 12 次免费调用）：带软要求的优胜美地 5 天（每天的路线、休息日、没排进去的列表、复制、看完整行程、接着说的例子都对），“这个季节有什么推荐的公园”（search agent 9 秒推荐四座、列成 1–4 的按钮），英文的锡安 3 天（英文的路线和按钮都对；最后一天“drive back to …”改成开头大写）。PR 的 Vercel 预览版要登录 Vercel，没用。顺带发现线上审查 agent 一直没跑过（镜像少拷了判分脚本），另开了 #139。
