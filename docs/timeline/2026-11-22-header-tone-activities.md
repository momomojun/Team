# 11-22：页头跟着页面深浅换颜色、首页上深下浅只换一次、新的活动页（分支 `feature/header-tone-activities`）

- 为什么做：仓库主人问首页只有上半页是深色、到“资料从哪来”突然变白，页头在深色页面上也是一条白的，这个转变合不合适；又提出把每座公园这段时间好的、热门的活动整理出来突出，这是独特的体验。
- 查了 Wabunka：它的首页也是上面约四成深藏青、下面一半多米色，页头一直是白的。所以“上深下浅”本身是照着它做的，问题在比例：我们深色有七八屏，米色只有中间一小段，后面又回到深色大图，看起来像被打断了一下，不像换了一章。
- 改了什么：
  - 页头：往下滚以后跟着下面那一段走，深色区块上是深色半透明（模糊后面的内容），浅色的上面是白底墨字（`site-header.tsx` 的 `toneUnder`：页头下沿那一点的元素往上找 `.theme-dark` / `.theme-light` / `data-header-tone`）。大图页头、公园页首屏、页脚标了深色；行程页的 Copilot 首屏本来就是深色，页头也跟着变深。公园菜单展开时还是白底。
  - 首页：上半页深色看风景（首屏、入口、当月精选、热门目的地、一句话排行程、按地区、博主路线），下半页米色是能做的事和资料（这个月的活动、资料从哪来、电影），只换一次；下半页从“11 月的公园活动”开始，对应 Wabunka 下半页开头的“Available Today”。收尾大图上的两张卡片各自是浅色，页头在两张卡片之间的照片上是深色。
  - 活动页（`/activities`，`/activities/1`–`12`、`/activities/all`）：`src/data/activities.ts` 原来只在公园页和攻略说明里显示，现在按月份汇总。一年里只有四个月以内的算“限时”（金色角标），限时的排前面，同样限时的按公园热门程度；先列“这个月最值得的” 6 个，再按片区列全部。页头照片用这个月最值得的第一个活动，每个月不一样。导航（5 项）、页脚、手机菜单加了“活动”。
  - 公园热门程度（各景点 Google 评论数加起来）原来首页、全部公园页各写一遍，挪到 `src/lib/park-popularity.ts` 共用。
- 数字：335 个活动，7–9 月每月 140 多个（一半限时），11 月 37 个，全年都有的 54 个。
- 验证：在浏览器里从首页顶上滚到底，页头依次是透明 → 深色 → 米色那段白色 → 收尾大图和页脚深色；看过活动页（11 月、2 月、7 月、全年）、英文版（没有混进中文）、手机宽度（不被撑宽）、行程页。新加 `tests/activity-cards.test.ts`（每个月都有、锚点不重复、1–12 月加全年正好是全部、限时的排前面）；`tsc`、`eslint` 干净（只剩原来的 3 个 `<img>` 提醒），网站 219 个测试通过。
