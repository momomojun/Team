  - README 的截图全部重拍（`npm run docs:screenshots`），社交预览图也换了；截图脚本跟着新页面改：景点地图、人多不多、油价各在自己的分页上，页头是整屏照片的页面往下滚到内容再截，行程页一直有后台请求时页面加载完就接着截。
  - GOALS.md 加了 W78（照着 Wabunka 改版），WR1、W23 的说明跟着改；DEVELOPMENT.md 的路线图注明改版。
