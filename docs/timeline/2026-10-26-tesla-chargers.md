# 10-26：公园页的“Tesla 充电”（分支 `feature/tesla-chargers`）

- 为什么做：仓库主人要 Tesla 的充电桩单独一页、有地图，有什么充电桩参考多方面的消息（GOALS O74）。原来只有实时信息页的“补能：充电桩”，按 NLR 现查、只列表，不分 Tesla 的超充和目的地充电。
- 查了哪些来源：
  - NLR 充电站数据（美国能源部 AFDC）：`ev_network` 是 Tesla（超充）和 Tesla Destination（目的地充电），有桩数、每个接口的功率、开放日期、最后核实日期、状态（开着、暂时不可用、在建和预计日期）；加拿大的也有（NRCan 提供），班夫、贾斯珀、幽鹤一样能查。
  - OpenStreetMap：brand / operator 写着 Tesla 的充电站，常有 24 小时、只给顾客用这些标签；公园附近的超充标了一半多（558 个里 309 个），目的地充电标得很少。
  - Tesla 官网的超充地图（tesla.com/findus）：返回 403，拦自动访问，不绕过。
  - supercharge.info：车主社区维护的超充地图，有开放的接口，但网站和 GitHub 上都没写数据的授权，所以不下载，只在每个超充旁边放一个“社区记录”的链接。
  - Open Charge Map 要注册拿 key，PlugShare 没有公开接口，都没用。
- 做了什么：`scripts/build-tesla.mjs`（`npm run data:tesla`）每座公园按补给点同样的半径查 NLR；OSM 一次查完美国、加拿大和两块海外领地所有标了 Tesla 的充电站（1,281 个，约 5 MB、两分钟），再按半径分给各公园（一座一座查时 Overpass 公共服务一直 502，一座要等十几分钟；查不到时只用 NLR、页面上写明，上次查到过的沿用上次的）；同一个站（超充 500 米内、目的地充电 300 米内）合成一条，OSM 上一个站画成几个点的并进去；超充取最近的 30 个，用 OSRM 一次算好从定位点和每家推荐住宿开过去多久；目的地充电只要景点、推荐住宿附近 8 英里内的，就在哪家推荐住宿（只认名字是一家店的，Springdale、Banff 这种小镇不算）、在哪个景点旁也写上。页面 `parks/[code]/tesla`：地图沿用 `ParkMap`（超充是砂岩红的点、上面写桩数），列表按车程排，每个站写车程、桩数和功率、24 小时 / 只给顾客 / 只有 Tesla 接口、在建、一年内新开、超过一年没核实，来源一行写两边都有还是只有一边、超充两边桩数不一样时写 OSM 的数；“住在哪里，离超充多远”一节、“出发前要知道”四条、数据说明。
- 结果：70 座公园里 62 座附近有 Tesla 的站，一共 558 个超充、319 个目的地充电（去重后）；超充里 304 个两边都有、249 个只在 NLR、5 个只在 OSM，11 个两边桩数不一样。附近一个都没有的：航海家、维尔京群岛、兰格尔–圣伊莱亚斯、冰川湾、北极之门、科伯克谷、夏威夷火山（大岛上 NLR、OSM 都没有）、美属萨摩亚，这几座不显示这一页。
- 检查：优胜美地最近的超充是 El Portal（8 个桩、250 kW），从优胜美地山谷开约 25 分钟；锡安是 Toquerville（2026 年 1 月开的，12 个桩、325 kW），约 40 分钟；班夫最近的超充在 Canmore，班夫游客中心、Cave and Basin、Upper Hot Springs 都有目的地充电。`tests/tesla.test.ts` 检查公园代码、住宿 id、超充按车程排、来源和站号对得上；中英文页面、手机宽度在浏览器里看过。
- 拿不准的：OSM 上只有超充、NLR 里没有的，可能是新开的、也可能已经撤了，页面上让人去 Tesla App 确认；同一个镇上 NLR 有时列着 2015 年的老站和后来开的新站（比如 Canmore 有 3 个），老站是不是还在没核实。
