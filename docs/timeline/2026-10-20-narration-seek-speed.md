# 10-20：讲解版能拉进度条、调倍速，地图配色按制图规矩收了一遍（分支 `feature/narration-polish`）

- 为什么做：PR #42 合并后仓库主人说“视频导出就先不做，把网页上播放的做好先”，又说“希望网页的讲解版可以拉进度条和调倍速”。
- 进度条：按天上色，分成开头、每天开场、开车、各站讲解、结尾几段；拖动时提示跳到哪一站，开车的段跳到点的位置、讲解的段从这一站开头讲；上一段 / 下一段（键盘左右键）、空格暂停；倍速 0.75–2 倍，朗读跟着变快，记在这台设备上。时间是按阅读时间估的，大概准。
- 地图（按 maplibre-cartography 技能）：播放时底图蒙一层淡纸色，路线才是主角；路线、步道放到底图文字下面，地名不被压住；卫星图上景点名字改成白字深色描边；控制条抬高，下面露出比例尺和 OpenStreetMap 的署名。
- 讲解词里汉字和英文地名之间补了空格（“去 Wawona”）；同一个地方的两站不再抢着念；朗读优先挑自然的声音。
- 用无界面 Chrome 在电脑（1280×800）和手机（390×844）上试过拖动、上一段 / 下一段、倍速、暂停、拖到结尾。
