# 11-21：网站改版第二批：照着 Wabunka 的观感整站重做（分支 `feature/site-redesign-b`）

- 为什么做：第一批（#122）只换了颜色，仓库主人看了说“没有大改看不出来效果”，要和 Wabunka 对齐：不只是结构，整个设计、页面观感、动画、流畅度都要看齐。先在浏览器里把 Wabunka 的首页、目的地页、体验详情页拆了一遍（版心 1216px、Spectral 衬线、金色 `#a48953` 标题配细线、金底深字按钮、照片格子之间 2–8px 的缝、悬停时照片 0.5–1 秒放大 2–5%、首屏大图交叉淡入加慢慢平移、页头压在大图上透明、滚下去变白底），再照着改。学的是做法，不照抄它们的标志、图片和文案。
- 拆的时候发现：Wabunka 只有首页和展示的区块是深藏青，列表页、详情页都是白底墨字、米色衬底。第一批把全站都换成了深色，这一批改成和它一样：首页、大图首屏深色，内页浅色（`.theme-dark` / `.theme-light` 两个类换同一套颜色变量）。
- 改了什么：
  - 颜色和字体（`globals.css`、`layout.tsx`）：默认浅色，首页套深色；金色按钮、选中统一成 `gold` 金底配深色字；“请务必慎重考虑”这类最醒目的提醒用 `alert` 深红底（原来跟着强调色，换成金色以后不够醒目）。标题和正文都换成衬线（英文 Spectral + 思源宋体，Wabunka 也是 Spectral），导航和小标签还是 Jost。
  - 动画和流畅度：首屏大图交叉淡入、放大一点慢慢往左平移；照片下载好了才淡出来（不会一块一块往下画）；悬停时照片慢慢放大一点；导航链接下面一条细线从左往右长出来；“往下看”一道细线往下流。去掉了开场动画（Wabunka 打开就是首屏大图，开场动画要等两三秒）。
  - 页头：左边站名、紧跟着 4 项导航，右边账号、简繁、菜单和金色的“开始规划”；压在大图上时透明，滚下去或者在别的页面是白底。页脚：炭灰底，中间站名，一行页面链接，下面按片区列公园。
  - 首页按 Wabunka 首页的顺序重排（约 10 屏）：首屏（站名、一句话、白色搜索框：打公园名列出公园，打一句话就带着去行程页填进 Copilot）→ 五个入口格子 → 当月精选（横着滑）→ 热门目的地（两张大图 + 一排小图，英文名横排、中文名竖排）→ 一句话排行程的三个示范（“照这句话排”）→ 按地区的照片拼贴 → 博主路线拼贴 → 米色的“资料从哪来”（只写真的数据来源和数字，不编评价）和“电影里的国家公园”（取景地照片当封面，点了才加载片方的 YouTube）→ 大图上两张白卡片。原来首页的公园目录、园外名胜、线描地图挪到新的“全部公园”页（`/parks`，按片区分段的照片卡片）。
  - 内页：页头换成整屏宽的照片慢慢平移、左下是标题（什么时候去、灵感、榜单、价格、全部公园）；公园页首屏是全屏大图，底下一条白条写基本情况和金色的“生成这个公园的攻略”（手机上白条放在照片下面）；公园概览照着 Wabunka 的详情页排成左边正文、右边基本情况；各页的区块标题统一成金色衬线字加一条细金线（`section-title`）；内页的版心收窄到 1216px（公园分页、行程页还是宽的，地图要地方）。
  - 行程页的 Copilot 首屏：照片亮一些，输入框换成白色；从首页搜索框、示范过来的话（`?q=`）先填进输入框，等用户按发送。
  - 顺手修的：博主路线里同一站有两条评价时 React 报 key 重复（班夫大道）。
  - 文档：`DEVELOPMENT.md`（globals.css、首页、site 三行，字体来源）、`GUIDE.md` 的界面约定；`scripts/screenshots.mjs` 改成等首屏照片下载好再截（原来等开场动画）。
- 验证：在浏览器里看过首页、全部公园、锡安和优胜美地的公园页（概览、景点地图）、行程页（Copilot 首屏、生成一份锡安 3 天的行程）、什么时候去、灵感、榜单、价格、后台和英文版首页；手机宽度（375 像素）下首页、公园页、行程页不被撑宽。`tsc`、`eslint` 干净（只剩原来就有的 3 个 `<img>` 提醒），网站 216 个测试通过。
- 还没做：行程页里每天的卡片、总览这些还是原来的排法（颜色、字体已经跟着换了）；README 的截图要等这一批合并以后重拍（`npm run docs:screenshots`）。
