# “明星同款”能不能收中国大陆明星：可行性调查（2026-10-20）

起因：`src/data/celebrities.ts` 现有 19 条里没有一条中国大陆明星（只有一位香港的张曦雯），10-16 的说明是“微博不登录看不了”。这次查的是：在不登录、不绕过登录墙、不用小红书的前提下，有没有办法找到、核对、在页面上显示或链接大陆明星在网站收录的公园里发的照片。

收录标准照 `celebrities.ts` 开头和 [agent-briefs/07-celebrity-spots-v2.md](../../agent-briefs/07-celebrity-spots-v2.md)：本人公开发的帖子 + 至少一家可靠报道确认人和地点；地点在网站收录的公园、名胜里；照片只用官方嵌入或链接，不转存。

## 一、各种办法试下来的结果

### 1. 微博单条帖子页：不登录打不开（不能用来核对）

- `https://m.weibo.cn/detail/<mid>` → 302 跳到 `visitor.passport.weibo.cn/visitor/visitor?...`（微博的“访客系统”，要跑 JS 拿访客 cookie）。
- `https://weibo.com/detail/<mid>` → 302 跳到 `passport.weibo.com/visitor/visitor?...`。
- 这一步就是一道机器验证，按规则不绕过，所以**我们这边没法直接打开微博原帖核对**。
- 微博没有像 Instagram `/embed/captioned/`、X oEmbed 那样公开、免登录、能放进别的网站的单帖嵌入（早年的“微博秀”“插入微博”组件早就停了）。所以页面上**只能放链接，不能嵌入**。
- 对网站的读者来说，链接到微博问题不大：目标用户大多有微博账号、手机上有 App。问题在我们这边核对不了。

### 2. 新浪自己的微博镜像页 `sina.cn/weibo/detail/<mid>.html`：不登录能看（可以用来核对）

- 搜索时发现新浪新闻把一部分微博帖子做成了公开页面，地址是 `https://sina.cn/weibo/detail/<mid>.html`，`<mid>` 和微博帖子的数字 id 一样。
- 实测 `https://sina.cn/weibo/detail/5355526919292138.html`：不登录就能看到发帖账号、**认证信息**（“微博认证：……”）、发帖时间、IP 属地和正文；页面顶上只有一个普通的“登录”按钮，不挡内容。抓取到的文字里看不到图片本身。
- 同一个 mid 用 m.weibo.cn 打开就被跳到访客系统（见上），说明这是新浪官方的公开页面，不是绕过。
- 限制：
  - 不确定是不是每条微博都有这个镜像页，看起来是新浪新闻收录过的才有；明星帖子有没有，要拿具体的 mid 试。
  - 有些 sina.cn 页面是“【授权·小红书】”转载的小红书内容，**这类一律不用**（规则不用小红书）。
- 建议用法：知道了一条明星微博的 mid（从新闻报道里拿），先用 sina.cn 镜像页核对“账号是本人认证账号、时间、正文、IP 属地”，页面上的链接给 `https://weibo.com/<uid>/<mid>` 原帖。

### 3. 中文娱乐新闻：能看，但我们的搜索工具基本搜不到

- 新浪（`k.sina.com.cn` 文章页实测不登录能看全文）、网易号、搜狐、凤凰、东网等页面本身不用登录。腾讯新闻有的旧链接已经 302 到“文章不存在”。
- 真正的瓶颈是**搜索**：WebSearch 是美国的搜索服务，中文娱乐新闻收录很差。这次用“明星 + 公园名 + 晒照 / 打卡 / 微博”试了十几种中文、英文组合（大峡谷、黄石、优胜美地、羚羊谷、马蹄湾、班夫、路易斯湖、梦莲湖、纪念碑谷，加上限定新浪、腾讯、网易、搜狐、凤凰、澎湃、中新网、新华网等域名），结果几乎全是旅行社线路和普通游记，没有一条是大陆明星的报道。
- 按人名搜（刘雯、何穗、奚梦瑶、雎晓雯、谷爱凌、宋茜、Angelababy、郑钦文、郎朗、李冰冰、郑爽、苏翊鸣、武大靖、张艺兴，WayV 的董思成、钱锟、肖俊，程潇、宋雨琦）也都没搜到和公园有关的报道。这不代表没有，只说明“不知道是谁、先按地点搜”这条路走不通。
- 唯一搜到的“华语明星在公园晒照”报道是香港东网 2026-10-18 的：前 Super Girls 成员**蔡明思（Jessica）**到美国旅行，去了羚羊峡谷和马蹄湾（https://hk.on.cc/hk/bkn/cnt/entertainment/20261018/bkn-20261018160113084-1018_00862_001.html ）。她是香港艺人，不是大陆的；报道没写她发在哪个平台、哪一段羚羊峡谷。

### 4. Instagram：大陆明星里用 Instagram 的主要是模特、少数演员和运动员，但不登录没法翻帖子

- Instagram 帖子能用 `/p/<code>/embed/captioned/` 核对和嵌入（现有 19 条都是这么做的），前提是先从报道里拿到帖子链接。
- 用 Instagram 的大陆明星：模特刘雯（@liuwenlw）、奚梦瑶（@mingxi11）、何穗、雎晓雯，Angelababy，部分演员和运动员（谷爱凌、郑钦文等）。
- 主页 `instagram.com/<账号>/` 不登录只显示最近十几张缩略图和自动生成的图片说明（实测刘雯的主页：没有配文、没有地点），翻不到旧帖，也不能按地点搜。所以 Instagram 只能作为“报道里给了帖子链接时”的核对和嵌入渠道，找不到新线索。

### 5. 综艺节目的官方 YouTube / B 站：能看能嵌入，但大陆综艺几乎没去过这些公园

- 腾讯视频（WeTV）、芒果 TV、东方卫视（SMG）、优酷都有 YouTube 官方频道，视频能嵌入（实测 `playableInEmbed: true`）；B 站搜索页不登录也能用。
- 查过的旅行综艺都没有在网站收录的公园里拍：
  - 《花儿与少年》1–8 季：意大利、西班牙、英国、土耳其、阿联酋、巴西、纳米比亚、南非、澳大利亚、湖南、沙特、克罗地亚、冰岛、智利、法国、坦桑尼亚、马达加斯加、埃及、捷克、挪威、墨西哥、秘鲁、阿根廷（中文维基）。
  - 《旅途的花样》第一季：摩洛哥、俄罗斯、挪威、丹麦。
  - 《奇遇人生》第一季第 2 期：春夏和阿雅在美国中部追龙卷风（腾讯视频官方频道 https://www.youtube.com/watch?v=DPu4d3OVSoE ），不是在国家公园里。
  - 《妻子的浪漫旅行》2025、2026 季：俄罗斯等，没有美国。
  - 《跟着贝尔去冒险》：丛林，没有美国公园。
- 想用这条路，要先有具体的节目和集数（比如某个综艺某一期在大峡谷录），再去官方频道找对应的那一期或片段。这次没找到这样的节目。

### 6. 其他

- B 站上明星本人的官方账号发的 vlog：B 站搜索能用，但搜“明星 vlog 羚羊谷”“明星 美国国家公园 综艺”出来的都是普通 UP 主和纪录片搬运，没有大陆明星本人的。
- YouTube 上搜到的华语艺人公园 vlog 都是港台的：台湾歌手閻奕格（Janice Yan）的优胜美地 vlog、香港 TVB 演员譚杏藍（Hana Tam）2019 年的羚羊谷 vlog、台湾网红黄可乐的羚羊谷 vlog。这些是本人官方频道的视频、可以嵌入，以后要收港台艺人可以考虑。

## 三、建议

1. **短期：明星同款先不收大陆明星，在 DEVELOPMENT.md 的说明里把原因从“微博要登录”改成更准确的说法**：微博单帖页有访客验证、没有公开嵌入；中文娱乐新闻本身能看，但我们的搜索工具搜不到；这次按地点、按人名试过都没找到合格的。
2. **如果仓库主人想继续做，推荐的办法是“先有人名和事件，再核对”**，不要再按地点盲搜：
   - 线索来源：仓库主人或组员自己记得的（“某某去过黄石”），或者在国内能用的搜索（百度、微博搜索）里查到的报道链接，交给 AI 助手核对。
   - 核对顺序：
     1. 新闻报道（新浪、网易、搜狐、凤凰、澎湃、中新网……）确认人和地点；
     2. 帖子在 Instagram 的，用 `/embed/captioned/` 核对，`platform: "instagram"`，页面上照现在的方式嵌入；
     3. 帖子在微博的，先用 `https://sina.cn/weibo/detail/<mid>.html` 核对账号认证、时间、正文（打不开就只信报道，`confidence` 最多 medium），`platform: "weibo"`，`postUrl` 写 `https://weibo.com/<uid>/<mid>`；页面上只放链接、不嵌入（`MediaEmbed` 对微博不加载任何东西）；
     4. 综艺、vlog 在官方 YouTube 频道有的，`platform: "youtube"`，用现有的 YouTube 嵌入；只在 B 站有的只给链接。
   - 类型里已经有 `"weibo" | "youtube"`；`celebrity-shots.tsx` 现在只在 `platform === "instagram"` 时嵌入，其他平台只显示原帖 / 主页链接，所以加微博条目不用改组件。YouTube 条目想在明星同款里也嵌入视频，要给组件加一个 `platform === "youtube"` 的分支（影视同款那边已经有 YouTube 的 `MediaEmbed`，可以照用）。
3. **港台艺人比大陆艺人好做**：大多用 Instagram 和 YouTube，有现成的嵌入；这次就碰到了蔡明思（羚羊峡谷、马蹄湾，东网 10-18 报道）、閻奕格（优胜美地 vlog）、譚杏藍（羚羊谷 vlog）三条线索。要扩充华语明星，可以先从这里做，每条照样要找到本人帖子 + 报道。
4. 不管哪条路，都**不用小红书**，sina.cn 上标着“授权·小红书”的转载也不用。
