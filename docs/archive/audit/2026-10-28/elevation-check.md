# 步道爬升三方核对（2026-10-28）

`npm run data:elevation` 按高程模型（Valhalla，约 30 米一格）算出每条步道的海拔剖面以后，和景点资料里写的爬升（`hike.gainFt`）比：差 40% 以上、而且差 60 米以上的列在这里，旁边附 AllTrails 上同一条步道的数字（仓库主人自己的 AllTrails 数据，只读）。

整体：234 条有资料爬升的步道，算出的和资料的中位数 1.02 倍；和 AllTrails 长度差不多的 234 条比，中位数 1.01 倍、平均差 25 米。下面这些大多不是高程模型的问题：

- **资料多半写错了**（AllTrails 和高程模型都比资料高得多）：拱门 Devils Garden 环线（资料 87 米，AllTrails 291 米）、Double O Arch（84 / 158）、峡谷地 Chesler Park（162 / 293）、尖峰石阵 Balconies 洞穴环线（30 / 116）、巨人柱 Tanque Verde Ridge（30 / 462，我们的路线只画到观景点）。要按 NPS 官网重查、改 `hike.gainFt`
- **高程模型偏高**（资料和 AllTrails 接近，我们算得高）：大弯圣埃伦娜峡谷、Boquillas 峡谷，峡谷地 Horseshoe Canyon，梅萨维德 Petroglyph Point：都沿着崖壁或者在峡谷底下走，30 米一格分不清谷底和崖顶；基奈峡湾 Exit Glacier 可能是测高程的时候冰川还盖着那里。页面上照样画剖面，只当形状看
- **路线和资料说的不是同一段**：优胜美地马里波萨巨杉林（地图上画到了上林，全程 5.8 英里；资料只到灰熊巨树，2 英里）、大盆地 Lexington Arch（画出来 7.8 英里，资料 5.6 英里）
- **说不准**：黄石下瀑布之巅（资料 183 米，AllTrails 76 米，我们 104 米）、布莱斯仙境环线（资料 579、AllTrails 469、我们 335）
- **大盆地 Baker Creek**：OSM 上的路线只有一个点（长度 0），不画剖面
