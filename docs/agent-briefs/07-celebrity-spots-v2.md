## 怎么找、怎么核对

- **不能登录 Instagram 或 X**，不要尝试登录，也不要绕过登录墙。用下面这些不需要登录的公开方式：
  - **找帖子**：
    - 用 WebSearch 搜新闻报道，比如"<明星> Yosemite Instagram"、"<明星> Grand Canyon photos"、"<明星> national park vacation"、韩文和日文的报道。报道里通常有原帖链接或嵌入。
    - 也可以搜 `site:instagram.com <公园名>` 这类结果。
  - **核对 Instagram 帖子**：
    - 用 WebFetch 打开 `https://www.instagram.com/p/<帖子代码>/embed/captioned/`，不需要登录，能看到发帖账号和配文；
    - 确认账号是明星本人的认证账号，配文或地点和报道一致。
    - 打不开、或者内容对不上的，不当成原帖链接，改用 `profileUrl`（本人主页），并在 `noteZh` 里说明。
  - **核对 X / Twitter 帖子**：
    - 用 WebFetch 打开 `https://publish.twitter.com/oembed?url=https://twitter.com/<账号>/status/<数字>`，返回的 JSON 里有发帖人和正文；
    - `platform` 填 `"x"`。
  - **现有 12 条**：逐条用上面的方法核对 `postUrl` 和 `profileUrl`。
    - 发现不对的：先找正确的帖子；找不到的，删掉 `postUrl`、只留主页，并写明原因。
    - 现有条目都要补上 `whoZh`，`nameZh` 和 `nameEn` 也要核对。
- **收录标准不变，而且更严**：
  - 每条要有明星本人公开发的帖子，加上至少一家可靠报道确认是这个人、在这个地方。
  - 地点必须在网站已收录的公园或名胜里。
  - 不收以下几类：
    - 违规的：越过栏杆、进热泉禁区、无人机违规等。
    - 只发了限时动态的。
    - 地点只是"看起来像"的。
    - 主角是未成年人的。
  - 拍法有危险的，`tipsZh` 里写安全的拍法。
- **数量**：目标是新增 20–30 条，大牌优先，宁缺毋滥。也可以同一个明星收几张不同地点的照片。

## 名字怎么写（用户特别要求）

- **`nameZh`**：写中文用户最常用的叫法，不要硬翻成拗口的音译。
  - 有通用中文名的用中文名，比如泰勒·斯威夫特、蕾哈娜、孙兴慜、刘雯。
  - 本来就用英文名、团名称呼的直接写英文，比如 Lisa、Jennie。
- **`nameEn`**：写英文名或罗马字。页面会把中英文名一起显示。
- **`whoZh`**：写一句话说明是谁，让不认识的人也知道。比如"BLACKPINK 成员、泰国歌手""美国流行歌手""韩国花样滑冰奥运冠军""《权力的游戏》女主角"。
