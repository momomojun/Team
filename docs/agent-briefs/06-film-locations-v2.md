# 任务：扩充"电影同款"，多收出名的电影、电视剧，每条配一张取景地实景照片

项目在 `D:\LLM\Team`。`src\data\films.ts` 里已经有 27 条电影、电视剧取景地。用户觉得太少，希望多收**大家都知道的片子**，并且每条都配上图片。

## 先读

- `src\data\films.ts`：数据格式 `FilmShot` 和开头的收录标准。新加的 `photoFile` 字段说明也在里面。照现有条目的写法和详细程度写。
- `src\data\parks.ts`：网站收录的公园和名胜，以及公园代码。
- `src\data\attractions\<代码>.ts`：景点列表，`id` 字段可以对应到 `attraction`。

## 要做的

1. **新增条目**：目标是总数达到 60 条左右，宁缺毋滥。
   - 优先收知名度高的：好莱坞大片、经典西部片、知名电视剧，中国观众熟悉的优先。
   - 华语电影、韩剧、日剧、综艺在这些公园取过景、并且有可靠来源的，特别值得收。
   - 可以挖的方向：
     - 星球大战：死亡谷其他取景点，比如 Golden Canyon、Dante's View、Desolation Canyon、Twenty Mule Team Canyon、Mesquite 沙丘。
     - 纪念碑谷：《回到未来 3》《2001 太空漫游》《独行侠》（2013）、《西部世界》、多部约翰·福特的西部片。
     - 拱门、峡谷地一带：《夺宝奇兵》其他场景、《西部世界》、《碟中谍》系列、《变形金刚 4》。
     - 鲍威尔湖、格伦峡谷：《人猿星球》《神秘博士》。
     - 大峡谷：《末路狂花》以外的片子。
     - 优胜美地：《星际迷航》系列。
     - 大烟山、仙纳度、阿卡迪亚，以及加拿大落基山（班夫、贾斯珀、幽鹤）。
     - 夏威夷火山、哈莱阿卡拉：比如《侏罗纪》系列只有真在公园里拍的才收。
     - 黄石、大提顿、冰川、红木、奥林匹克（《暮光之城》）等。
   - **收录标准不变**：
     - 每条至少要有一个可靠来源确认"这部片在这个地方拍过"：NPS 或 Parks Canada 的页面、州或地方电影委员会、片方材料、主流媒体。IMDb 用户编辑的取景地页面只能作参考。
     - 只收在网站已收录的公园、名胜里拍的，或者就是网站的某个景点本身。
     - 拍在附近州立公园、私人土地上的：只有那个地方本身就是网站景点时才收，并在 `placeZh` 里写清归谁管。
     - 不剧透关键结局。
2. **给每一条配照片**，现有的 27 条也要补：
   - `photoFile` 填 Wikimedia Commons 上的文件名，不带 `File:` 前缀，必须是**取景地的实景照片**（风景、地标），不能用剧照、海报、截图。
   - 授权只能是 CC BY、CC BY-SA、CC0 或公有领域，不收 NC/ND 的。用 WebFetch 打开 `https://commons.wikimedia.org/wiki/File:<文件名>` 确认文件存在、看授权、看画面对不对。
   - 尽量选能看出片中那个画面的角度，比如阿甘点就选公路直线延伸到孤峰的照片。
   - 找不到合适照片、而 `attraction` 对应的景点本身有图集的，可以不填 `photoFile`（页面会用景点图集的第一张），但优先自己挑一张更贴近电影画面的。
3. `titleZh` 用中国大陆最常用的译名，`creditsZh` 写导演或主演，一两个人名就够。

## 写法和安全

- 和现有条目一致：
  - `sceneZh` 写拍的是哪场戏。
  - `howToZh` 写站在哪、往哪拍、几点光线最像、要不要许可。
  - `tipsZh` 写具体的安全提醒和小技巧。
- 用简体中文，说人话。
- 有危险的拍法（崖边、站在公路中间）一定写安全的替代做法。
- 在文件开头的注释里补上"查过但没收"的片子和原因。

## 只改一个文件

只改 `src\data\films.ts`，别的文件都不要动，不要动 git。用 WebSearch 和 WebFetch 查资料，不用浏览器面板。
