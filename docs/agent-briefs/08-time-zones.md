# 任务：调研网站上每座公园、名胜的时区"坑"，写成一份带来源的清单

项目在 `D:\LLM\Team`，是一个美国国家公园行程规划网站。行程里的每个时间（几点到、几点开门、导览几点出发、日出日落）都按公园的时区算。每座公园的 `timeZone` 字段写在 `src\data\parks.ts` 里，用的是 IANA 名称，比如 `America/Denver`。

用户提醒有几类情况会让人搞错时间：

1. **一座公园横跨两个时区**，或者公园和旁边的门户城镇不在同一个时区。
2. **同一个地方，不同的项目按不同的时间计时**。比如：
   - 亚利桑那州不实行夏令时，但纳瓦霍保留地实行夏令时；
   - 佩吉市（马蹄湾）、羚羊峡谷各导览公司、纪念碑谷、鲍威尔湖的码头，分别按哪个时间算；
   - 波浪谷抽签按犹他时间。
3. **手机自动切换时区**：手机按信号塔定时间，在边界附近会自动跳到另一个时区，导致手机上的时间和导览、入园、日出时间对不上。
