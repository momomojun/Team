# 任务：给“电影同款”和“明星同款”写英文版（按英语母语的写法写，不是翻译）

项目在 `D:\LLM\Team`，是一个美国国家公园行程规划网站。英文版 `/en` 给英语母语的读者用，会拿去做课程展示，**英文质量要像美国资深旅行作者从头写的**。

## 先读这些

1. **`D:\LLM\Team\docs\ENGLISH.md`**：写法规范（语气、事实、地名、英制单位、日期时间、本地化、术语表），必须逐条遵守。
2. 中文数据源，用来看清每段中文是什么字段、讲哪部片、哪位明星：
   - `D:\LLM\Team\src\data\films.ts`：电影、电视剧取景地。字段说明在文件开头的类型定义里（placeZh 地点、sceneZh 拍的是哪场戏、howToZh 怎么拍同款、tipsZh 提示、noteZh 说明、creditsZh 主创）。英文片名用 `titleEn`，导演、演员用英文名。
   - `D:\LLM\Team\src\data\celebrities.ts`：明星同款。`nameZh` 的英文就用 `nameEn`；`whoZh` 是一句话介绍这个人，英文写成英语读者熟悉的说法（比如 "BLACKPINK member and Thai singer"）；`shotZh` 是照片里怎么拍的，`howToZh`、`tipsZh` 是怎么拍同款和安全提醒，`noteZh` 是来源说明。
   - 公园名见 `src\data\parks.ts`；景点的英文名在 `src\i18n\en\content\attractions-<公园代码>.ts`（键是中文名），同一个景点必须用同一个英文名。

## 要做的

两个文件：`D:\LLM\Team\src\i18n\en\content\films.ts`（约 164 条空的）和 `D:\LLM\Team\src\i18n\en\content\celebrities.ts`（约 63 条空的）。内容是 JSON 对象：键是中文原文，值是英文，空字符串表示还没写。

- **把每个空字符串都写成英文。** 键一个字都不能改，不能删条目、加条目。已经写好的英文不用动。
- 值是 JSON 字符串：要用直双引号写成 `\"`，或用弯引号 “ ”。最后一条后面不要逗号，文件必须还能当 JSON 解析。
- 只改这两个文件，别的都不动。不要动 git，不要运行 `npm run i18n:en`。不用浏览器面板；拿不准人名、片名的英文写法时，用 WebFetch 查 Wikipedia、IMDb 或 NPS 官网（WebSearch 本轮额度可能已经用完）。

## 特别注意

- **单位换成英制**（公里→英里，米→英尺），四舍五入规则见 ENGLISH.md；时间用 12 小时制。
- **事实一个都不能丢**：年份、日期、价格、规定、谁拍的、哪家媒体报道的都要保留。中文本身矛盾或像写错了的，照写，并在回报里列出来。
- 场景描述不要剧透结局（中文没剧透的，英文也别加）。
- 中文里“原帖链接没拿到”“地点按某某报道”这类说明要保留意思。
- 中文里专门写给华人看的内容按 ENGLISH.md 的本地化一节改写。
- 同一段中文只有一个条目，写成在各处都通用的说法。

## 做完自查

在 `D:\LLM\Team` 目录下运行：

```
node scripts/check-en.mjs films celebrities
```

必须输出 `OK`（没有空值、英文里没有汉字、JSON 合法）。脚本列出“可能没换英制”的条目，逐条看：该换的换，括号里附的公制可以保留。
